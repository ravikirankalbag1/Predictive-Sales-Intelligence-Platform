# Exploratory Data Analysis (EDA)

## 1. Objective
- Understand the dataset
- Validate data quality
- Discover business patterns
- Identify variables useful for ML
- Detect anomalies

## 2. Data Quality Assessment
| Check                  | Status |
| ---------------------- | ------ |
| Missing Values         | None   |
| Duplicate Primary Keys | None   |
| Referential Integrity  | Passed |
| Data Types             | Valid  |

## 3. Dataset Overview
The dataset contains 10000 customers who did 7 lakh transactions in last 5 years (2021-2025) across 1820 products spread across 5 categories purchasing from 7 stores located accross the country.
