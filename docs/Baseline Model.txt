3) Establish the MLflow experiment structure.
Experiment: The overarching container for your specific machine learning problem (e.g., "property_price_regression").
Parent Run: Represents a single model architecture (e.g., a parent run named "XGBoost_Baseline").
Child Runs: Nested directly inside the Parent Run. Each child represents a single hyperparameter iteration generated during RandomizedSearchCV or GridSearchCV.
